Créer le composant Input
- Powercoach UI Input est un wrapper de Base UI Input et doit exporter le même nom ;
- Les seules différences anatomiques avec Base UI Input est l'ajout d'un add-on dans un root. Cet add-on est une identification visuelle de l'input et propose un alignement "start" par défaut, mais je peux choisir "end". Add-on est de type élément React et est une leaf à part dans l'anatomie. Un traitement visuel spécial doit être pris en compte lorsque Add-on est un SVG / Icon : centrage, taille adaptée (cf assets) comme c'est le cas sur Button dont il doit reprendre les codes pour la cohérence visuelle. Je propose donc qu'on ait Input.Root, Input.AddOn et Input.Control ;
- Propose une prop size : xs, md, xl (default) qui fait varier proportionnellement toutes les metrics. Toutes les assets montrent la version xl ;
- L'apparence finale et l'animation doivent être strictement identiques aux assets ;
- Moteur d'animation CSS uniquement via un @utility tailwind (pas de composant dédié). Rendre cette animation partageable. D'autres éléments de formulaire l'utiliseront.
