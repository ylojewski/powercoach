Créer le composant Field
- Field est un wrapper de Base UI Field et doit exporter le même nom ainsi que la même anatomie ;
- Field.Control doit générer un Powercoach UI Input (pas Base UI) qui doit être compatible avec Field de Base UI s'il ne l'est pas déjà, tout comme Base UI Input est compatible
- Field.Description doit générer et être contrôlé comme un Hint, waitingContent doit être mandatory et s'afficher en tone muted
- Il doit afficher les erreurs dans le Hint en intent destructive avec pour chaque erreur un item hint dédié
- Field.Label doit utiliser Heading en size sm
- Si Field.Control est required, Field.Label doit afficher une étoile après le label
- Field doit transférer autant que possible les props des components internes d'Input, de Hint et de Heading (tout commme Hint forward actuellement les textProps)
